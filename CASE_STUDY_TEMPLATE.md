# Case Study Intake — The Work (about.html)

When you have a new case study, send the items below and it'll get built into "The Work" section in the same format as the Tremoring Pine Healing one. Any section marked optional can be skipped — just say so.

## 1. Case identity
- Client/case name
- Industry, short label (e.g. "Health & Wellness")

## 2. Headline
The section reuses **"What we built together."** as a generic headline across case studies so it doesn't need rewriting each time. Flag it if this case needs its own specific headline instead.

## 3. Results table
One row per metric: **Metric name | Result | % Change** (or a plain note like "First 30 Days" for counts that don't have a clean baseline to compare against).

Example (Tremoring Pine Healing):
| Metric | Result | % Change |
|---|---|---|
| Followers | 131 | +40.86% |
| Total Account Views | 10,030 | +1,710% |
| Avg. Reach per Day | 228 | +781% |
| Total Saves (Reels) | 44 | First 30 Days |
| Total Shares (Reels) | 45 | First 30 Days |
| Inbound Enquiries (Leads) | 1 | First Inbound Lead |

**What I need:** the raw numbers plus the baseline you're measuring against. Get this wrong and the percentages won't be internally consistent (this happened once already) — so if there's any ambiguity about which starting point a % change is measured from, flag it rather than leaving it implied.

## 4. Before / After images
Two profile screenshots. They'll get cropped to: nav bar → avatar + stats → bio + link. Cut off before any "Followed by…" row, action buttons, or post grid — just the clean identity/stats block.

**What I need:** the full, uncropped screenshots. Don't pre-crop — send the whole thing and it'll get cropped to match the framing above.

## 5. Industry validation / notable moment (optional)
A screenshot of a real, notable public reaction — a comment from someone notable, a feature, a share, etc. — plus a one-sentence caption on why it matters.

**What I need:** the actual screenshot showing the real interaction (not a text-message-about-it screenshot — the real comment/like/mention itself, if you have it), and the one-line context for the caption.

## 6. Testimonial
- Quote, verbatim
- Attribution: name + role/title (e.g. "Jen H., Business Owner")

## 7. Post Performance (3 examples recommended)
For each post:
- The actual reel/post cover image (the real thumbnail, not an analytics screenshot)
- The hook/caption text
- Stats (views · saves, or whatever's most relevant)
- The platform URL (Instagram, etc.) so the cover links out to the real post

## How to send assets
Drop images in a Google Drive folder and share the link — that's the only way images actually make it into the site (pasted-into-chat images can't be extracted, only Drive links or real file uploads).

## What gets skipped if you don't provide it
- No notable moment → that block is left out entirely, not shown as empty.
- No testimonial yet → same, left out until you have one.
- Missing a stat → its row is left out of the table rather than guessed at.
